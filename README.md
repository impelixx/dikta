# Дикта

Push-to-talk диктовка на русском языке — распознавание речи полностью на вашем
компьютере, без облака и подписок. Под капотом — [GigaAM](https://github.com/salute-developers/GigaAM)
(Sber) через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx), десктоп-обвязка
на Tauri (Rust) + тонкий TS-фронт без фреймворков.

## Возможности

- **Push-to-talk и toggle хоткеи** — свои комбинации для каждого режима, ловятся глобально в любом приложении
- **Автостоп по тишине** — регулируемая чувствительность и длительность паузы (от «шёпот — тишина» до «стройка»)
- **Живые субтитры** — уже наговоренное видно прямо во время речи, не только после
- **Плавающий индикатор** поверх любого приложения — не нужно переключаться на окно Дикты, чтобы видеть статус
- **Автовставка текста** в фокусное поле, с гарантированным fallback в буфер обмена
- **4 модели GigaAM v3** (CTC/Transducer, с пунктуацией и без) — переключаются на лету из трея, с реальными замерами скорости
- **Своя модель с Hugging Face** — любая sherpa-onnx-совместимая модель по repo id
- **Выбор микрофона** и три темы (крем/терракота, мятная, лавандовая)
- **История с поиском** и статистика активности по дням
- Живёт только в трее — не занимает Dock/панель задач; крестик прячет окно, а не закрывает приложение

## Запуск

```bash
npm install
npm run tauri dev
```

При первом запуске модель нужно скачать прямо в приложении: Настройки → «Модель
распознавания» → «Скачать» у любого из вариантов GigaAM v3 (~260–280МБ).

На macOS система запросит доступ к микрофону, а для автовставки текста — ещё и к
Accessibility (System Settings → Privacy & Security). Без Accessibility текст всё
равно гарантированно попадёт в буфер обмена — просто вставьте вручную `⌘V`.

## Модели

Используются готовые ONNX-экспорты GigaAM v3 из sherpa-onnx model zoo — конверсия
из PyTorch не нужна. Скорость декодирования замерена локально (`cargo run
--example benchmark_models --release` в `src-tauri`) и показана прямо в интерфейсе,
а не выдумана. Лицензия самой модели GigaAM — **некоммерческая** (GigaAM License
NC); код приложения при этом свободен (см. «Лицензия» ниже) — модель скачивается
отдельно во время использования, а не распространяется вместе с кодом.

## Промо-сайт

Статическая страница в [`site/`](site) — публикуется на GitHub Pages через
`.github/workflows/deploy-site.yml` при пуше в `main` (один раз нужно включить
Settings → Pages → Source: GitHub Actions в самом репозитории). Ссылку на
репозиторий в футере/CTA сайта надо проставить вручную (`repoUrl` в конце
`site/index.html`) после публикации на GitHub.

## Релизы

`.github/workflows/release.yml` по тегу `vX.Y.Z` собирает инсталляторы под macOS
(universal), Windows и Linux через `tauri-action` и публикует черновик GitHub
Release. Сборка не подписана сертификатом Apple Developer — при первом запуске на
macOS нужно обойти Gatekeeper (System Settings → Privacy & Security → «Open
Anyway»).

## Стек

Rust (tauri 2, sherpa-rs, cpal, rusqlite, enigo, ureq) + TypeScript без фреймворка
(uPlot для графиков).
